======================== فیچر احراز (مرحله‌به‌مرحله) ========================

ثبت‌نام:
درخواست → اعتبارسنجی → نوشتن کاربر در دیتابیس → جواب
                 └─ رویدادمحور: ایمیل خوش‌آمد → صف

لاگین:
درخواست → خواندن کاربر → چک رمز → ساخت برگه عبور
       → برگرداندن برگه به مرورگر/اپ  ★ همزمان
         (برگه پیش کلاینت می‌ماند)

خروج:
درخواست → بی‌اعتبار کردن تمدید → جواب

تازه‌سازی برگه:
برگه تمدید → چک → برگه دسترسی جدید → کلاینت

ورود بیرونی (مثل گوگل):
برگشت بیرونی → وصل به کاربر داخلی → صدور برگه داخلی → کلاینت


==================== جریان برگه عبور (ستون فقرات هویت) ====================

احراز ──برگه عبور──► مرورگر/اپ
مرورگر/اپ ──همان برگه در سربرگ──► محصول / دستیار / چت‌بات
هر سرویس مقصد خودش برگه را چک می‌کند

درست: کلاینت حامل برگه است
غلط: نگهبان تأیید را از جنگو برای گو بفرستد


======================= فیچر محصول (مرحله‌به‌مرحله) =======================

پ۱) دروازه برگه عبور ── اگر رد → توقف
پ۲) کاتالوگ ── پرسش دیتابیس ── جواب همزمان
پ۳) سبد ── خواندن/نوشتن مستقیم دیتابیس
پ۴) سفارش ── نوشتن مستقیم دیتابیس ★ بدون صف
پ۵) وضعیت پرداخت ── به‌روزرسانی دیتابیس

بعد از سفارش موفق (رویدادمحور):
فاکتور / ایمیل رسید / بررسی تقلب ──► صف


============= فیچر دستیار + چت‌بات + جستجو (مرحله‌به‌مرحله) =============

گ۱) دروازه برگه عبور ── اگر رد → توقف
گ۲) دروازه پرداخت/اشتراک ── اگر رد → توقف
فقط بعد از هر دو دروازه:

دستیار:
سوال → بازیابی از موتور جستجو → ساخت جواب مدل زبانی
    → ثبت مصرف در دیتابیس
    → نوسازی ایندکس سنگین ──► صف

چت‌بات:
همان دروازه‌ها → مدیریت جلسه → ذخیره پیام‌های لازم
         → جواب → کارهای جانبی سنگین ──► صف


================== لایه رویدادمحور (فقط کار سنگین) ==================

                    ┌──────────────────────────────┐
   publish task     │  ردیس = کارگزار صف            │
 ─────────────────► │  صف بالا / معمولی / پایین     │
 از احراز/محصول/هوش │  صف = نوبت کارها              │
                    └──────────────┬───────────────┘
                                   │
                                   ▼
                    ┌──────────────────────────────┐
                    │ کارگران: کارگر-۱/۲/۳         │
                    │ ایمیل / ایندکس / فاکتور/آمار │
                    └──────────────┬───────────────┘
                                   │
                                   ▼ نتیجه مهم
                    ┌──────────────────────────────┐
                    │ دیتابیس اصلی (منبع حقیقت)    │
                    └──────────────────────────────┘

رویدادمحور یعنی: کار فوری جدا از کار تأخیری
رویدادمحور نیست: «اگر یک فیلد چک نشد بقیه را نادیده بگیر»


======================= دو مسیر ثبت داده ========================

مسیر همزمان (مستقیم):
سرویس ──────────────► دیتابیس اصلی ──► جواب فوری
مثال: لاگین، سفارش، چک اشتراک، لیست محصول

مسیر نوبتی (رویدادمحور):
سرویس ──► صف ──► کارگر ──► نوشتن نتیجه مهم در دیتابیس
مثال: ایمیل، ایندکس بزرگ، فاکتور سنگین


======================= دیتابیس اصلی ========================

                    ┌─────────────────────────────┐
                    │        پستگرس               │
                    │                             │
   باید بماند:      │ کاربر، سفارش، پرداخت،       │

=========== صف / همزمانی / موازی‌کاری در همین شماتیک ===========

موازی‌کاری:
چند پاد با هم → جنگو-۱ و جنگو-۲ ، گو-۱ و گو-۲ و ...

همزمانی:
داخل یک پاد چند درخواست با هم جلو می‌روند

صف:
کارها نوبت می‌گیرند (بالا → معمولی → پایین)


=========== معماری تمیز + قوانین مسئولیت‌ها ===========

داخل هر سرویس:
[ ورودی درخواست ] → [ منطق کسب‌وکار ] → [ دسترسی داده ]

بین سرویس‌ها:
احراز ≠ محصول ≠ هوش ≠ کارگر صف
هر کدام یک مسئولیت اصلی


==================== نقشه صاحب فیچر ====================

احراز:     ثبت‌نام / لاگین / خروج / تمدید / ورود بیرونی
محصول:     کاتالوگ / سبد / سفارش / پرداخت سفارش
هوش:       دستیار / چت‌بات / بازیابی جستجو
کارگران:   ایمیل / ایندکس / فاکتور / آمار


==================== متن ۳۰ ثانیه‌ای ====================

ترافیک → تقسیم فشار → نگهبان
احراز چندپاد → برگه به کلاینت
کلاینت برگه را به محصول/هوش می‌دهد
آن‌ها خودشان چک می‌کنند
فوری → مستقیم دیتابیس
سنگین → صف → کارگر → برگشت نتیجه مهم به دیتابیس
چند پاد = موازی‌کاری | چند درخواست در یک پاد = همزمانی | نوبت = صف
